aboutme

A small floating bubble for your website. Tap it and your blog, GitHub, CV and socials appear around it. It is running on this page: look in the corner.

1. Write your links

Save this as profile.json on your site, with your own name and links.

{
  "schemaVersion": 1,
  "name": "Your name",
  "tagline": "What you do, in a few words",
  "links": [
    { "id": "blog", "label": "Blog", "url": "https://example.com/", "icon": "blog" },
    { "id": "github", "label": "GitHub", "url": "https://github.com/your-username", "icon": "github" },
    { "id": "email", "label": "Email", "url": "mailto:you@example.com", "icon": "email" }
  ]
}

2. Add one script tag

Paste one of these into the <head> of your pages.

From npm, through jsDelivr

<script src="https://cdn.jsdelivr.net/npm/@tiennm99/aboutme@1" data-profile="/profile.json" defer></script>

From this project's GitHub Pages

<script src="https://tiennm99.github.io/aboutme/aboutme.js" data-profile="/profile.json" defer></script>

From your own site

Download aboutme.js and upload it next to your pages.

<script src="/aboutme.js" data-profile="/profile.json" defer></script>

No file to host? Leave out data-profile and put the JSON between <script ...> and </script> instead.
