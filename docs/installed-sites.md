# Installed sites

Every site that loads the widget. After each widget release, open each live URL
and check the bubble and panel. Keep this list current: add a row when you add
the tag to a site, remove it when you take it out.

All sites load the moving major tag `@1`, so a 1.x release reaches them without
editing the sites. A site pinned to an exact version says so in its row.
