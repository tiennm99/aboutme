# @tiennm99/aboutme

A floating bubble that shows links about a site's author. Drag it onto the target at
the bottom of the screen, or press "Hide", and it stays hidden for a period you choose.

```html
<script
  src="https://cdn.jsdelivr.net/npm/@tiennm99/aboutme@1"
  data-profile="https://<your-worker>.workers.dev/profile.json"
  data-hide="7d"
  defer
></script>
```

The profile format is in [`profile.schema.json`](profile.schema.json). Options, the
profile Worker and anonymous counts: [github.com/tiennm99/aboutme](https://github.com/tiennm99/aboutme).
