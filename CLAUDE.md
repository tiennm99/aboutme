# aboutme

- `docs/installed-sites.md` lists every site that loads the widget. Keep it
  current whenever the tag is added to or removed from a site.
- After each widget release, check every live URL in that list: the bubble
  loads, the panel opens, and nothing overlaps the site's own controls.
- Release through a `v*` tag (see "Releasing the widget" in `docs/usage.md`);
  the Publish workflow publishes to npm.
